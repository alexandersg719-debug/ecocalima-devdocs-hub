# Onboarding del Proyecto

## Bienvenido a EcoCalima

EcoCalima es una plataforma de ecoturismo diseñada para mejorar la experiencia turística en Calima El Darién mediante herramientas digitales sostenibles.

---

## Objetivo del onboarding

Permitir que cualquier desarrollador pueda:

- Comprender el proyecto
- Instalar el entorno
- Ejecutar la aplicación
- Entender la arquitectura
- Contribuir rápidamente

---

## Tecnologías utilizadas

- Python
- Flask
- MkDocs
- GitHub Actions
- GitHub Pages

---

## Instalación rápida

```bash
git clone https://github.com/alexandersg719-debug/ecocalima-devdocs-hub.git
```

```bash
cd ecocalima-devdocs-hub
```

```bash
pip install -r requirements.txt
```

```bash
python app/app.py
```

---

## Estructura principal

```text
docs/ → documentación
app/ → aplicación principal
.github/ → CI/CD
```

---

## Flujo de trabajo

1. Crear rama
2. Realizar cambios
3. Crear commit
4. Push
5. Pull Request

---

## Tiempo estimado de onboarding

15 minutos.
