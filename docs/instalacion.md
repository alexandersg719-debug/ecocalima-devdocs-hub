# Instalación del Proyecto

## Requisitos

- Python 3.11+
- Git
- VS Code

---

## Clonar repositorio

```bash
git clone https://github.com/alexandersg719-debug/ecocalima-devdocs-hub.git
```

---

## Entrar al proyecto

```bash
cd ecocalima-devdocs-hub
```

---

## Instalar dependencias

```bash
pip install -r requirements.txt
```

---

## Ejecutar proyecto

```bash
python app/app.py
```

---

## Ejecutar documentación

```bash
python -m mkdocs serve
```
