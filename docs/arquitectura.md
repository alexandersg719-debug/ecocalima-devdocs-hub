# Arquitectura del Sistema

## Arquitectura General

EcoCalima utiliza una arquitectura cliente-servidor.

---

## Componentes

### Frontend

Encargado de:
- navegación
- interfaz visual
- formularios
- reservas

---

### Backend

Desarrollado en Python Flask.

Funciones:
- lógica del sistema
- validación
- reservas
- recompensas ecológicas

---

### Documentación

Implementada mediante:
- MkDocs
- Markdown
- GitHub Pages

---

## Diagrama General

```text
USUARIO
   ↓
INTERFAZ WEB
   ↓
BACKEND FLASK
   ↓
GESTIÓN DE RESERVAS
   ↓
SISTEMA ECOLÓGICO
```

---

## Beneficios de la arquitectura

- Escalabilidad
- Mantenibilidad
- Facilidad de despliegue
- Modularidad
