# 🌿 EcoCalima DevDocs Hub

## Plataforma de Ecoturismo y Sostenibilidad

EcoCalima DevDocs Hub es una plataforma de documentación técnica diseñada para apoyar el desarrollo de soluciones digitales enfocadas en el ecoturismo sostenible en Calima El Darién.

El proyecto busca integrar herramientas tecnológicas modernas para mejorar la experiencia turística, promover la educación ambiental y fortalecer la sostenibilidad del ecosistema.

---

# 🚀 Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| Python | Desarrollo backend |

| MkDocs Material | Portal DevDocs |
| GitHub | Control de versiones |
| GitHub Pages | Despliegue |
| GitHub Actions | CI/CD |
| Markdown | Documentación técnica |

---

# 🌎 Problemática

El crecimiento del turismo en Lago Calima ha generado diferentes problemáticas ambientales y organizacionales, entre ellas:

- Manejo inadecuado de residuos
- Desorganización de reservas
- Escasa educación ambiental
- Impacto negativo sobre el ecosistema
- Falta de herramientas tecnológicas sostenibles

EcoCalima surge como una alternativa digital que busca fortalecer el turismo responsable mediante procesos tecnológicos modernos.

# 🎯 Objetivos

## Objetivo General

Diseñar un portal DevDocs profesional que documente una plataforma tecnológica orientada al ecoturismo sostenible en Calima El Darién.

## Objetivos Específicos

- Implementar documentación técnica moderna.
- Diseñar arquitectura escalable.
- Crear ADRs para toma de decisiones.
- Implementar flujo de trabajo colaborativo.
- Aplicar despliegue y control de versiones.
